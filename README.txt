PROJECT PERPUSTAKAAN - VERSI PHP DASAR

Nama database:
db_rehan_xiirpl1_paket4

File utama:
index.php
connection.php
buku.php
anggota.php
users.php
peminjaman.php
pengembalian.php
style.css

Tidak memakai auth.php atau framework.

CARA DI HP:
1. Extract folder ini.
2. Buka foldernya dari Acode.
3. Pastikan database db_rehan_xiirpl1_paket4 sudah dibuat dan database_baru.sql sudah diimport.
4. Sesuaikan connection.php jika password MariaDB berbeda.
5. Jalankan lewat A Web Server.

CARA DI PC:
1. Copy folder ini ke htdocs.
2. Buat/import database dengan nama yang sama.
3. Sesuaikan connection.php jika username/password MySQL PC berbeda.
4. Buka http://localhost/perpus_acode/

ALUR:
Anggota -> Buku -> Peminjaman -> Pengembalian.
Saat pinjam stok berkurang. Saat kembali stok bertambah.
